\# SpendWise Dashboard Shell



\## About the Project



SpendWise is a responsive financial dashboard shell designed to help users view and understand their spending categories in one place.



This project was created as a foundation for a future financial management capstone project.



\## Features



\- Responsive dashboard layout

\- Sidebar navigation

\- Dashboard header

\- Six financial category cards

\- Recent activity section

\- CSS Grid for the main dashboard and card layout

\- Flexbox for navigation, header, cards, and activity items

\- CSS custom properties for the color theme

\- Hover and keyboard focus micro-interactions

\- Responsive mobile layout

\- Dark theme using the user's system preference



\## Financial Categories



1\. Food

2\. Transport

3\. Rent

4\. Entertainment

5\. Savings

6\. Utilities



\## Technologies Used



\- HTML5

\- CSS3

\- CSS Grid

\- Flexbox

\- CSS Custom Properties

\- CSS Media Queries



\## Responsive Design



The dashboard changes to a single-column layout on screens smaller than 768px.



The responsive layout can be tested using the browser's DevTools Device Toolbar.



\## Micro-interactions



Dashboard cards include hover and keyboard focus effects.



The effects use:



\- `transform`

\- `box-shadow`

\- CSS transitions

s

The transition duration is 200ms.
